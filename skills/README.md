# Skills

This directory holds two skills, used in this order:

1. `pdf-to-md/`: manuscript to Markdown, section audit, and article sidecar.
2. `csag-extraction/`: Markdown and sidecar to a validated CSAG `PaperExtraction`.

The `csag` command wraps both; the repository `README.md` shows the workflow.
Each skill directory is self-contained (`SKILL.md`, `references/`, `scripts/`,
and the schema under `csag-extraction/assets/`), so a copy runs unchanged.
