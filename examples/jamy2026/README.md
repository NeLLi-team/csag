# Jamy 2026 plastid genome example

This directory holds the source PDF, converted Markdown, sidecars, and
curated CSAG for:

> Identification of a deep-branching lineage of algae using environmental
> plastid genomes. DOI: 10.1038/s41467-025-67401-4.

The manuscript text reports a Creative Commons Attribution 4.0 International
license, so the PDF and the derived files are included.

Included files:

- `s41467-025-67401-4.pdf`: source PDF (checksum in `example_manifest.json`)
- `s41467-025-67401-4.md`: converted Markdown
- `s41467-025-67401-4.section_audit.json`: section audit
- `s41467-025-67401-4.article.json`: article sidecar
- `paper_extraction.json`: the curated CSAG
- `paper_extraction.validation.json`: validator report
- `paper_extraction.quality.json`: quality report
- `example_manifest.json`: source, license, included files, and
  interpretation

The CSAG validates with the `paper_local` profile and has completeness score
1.0.
