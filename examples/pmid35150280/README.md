# PMID 35150280 example

This example is the CSAG extraction of PMID 35150280, "Giant Viruses Encode
Actin-Related Proteins" (DOI 10.1093/molbev/msac022). It is a compact
biological worked example with assertions, evidence links, inference steps,
critiques, knowledge gaps, and QA items.

Included files:

- `paper_extraction.json`
- `paper_extraction.validation.json`
- `paper_extraction.quality.json`
- `example_manifest.json`

The Markdown, section audit, and article sidecar are not included.
`example_manifest.json` records the PubMed source record, DOI, license,
validation profile, included outputs, and the reason each input is missing.

## Interpretation

The extraction captures the assertion that giant viruses encode
actin-related proteins and links it to comparative and phylogenetic evidence.
