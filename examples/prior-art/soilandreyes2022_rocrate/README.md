# RO-Crate prior-art fixture

This fixture covers "Packaging research artefacts with RO-Crate"
(`10.3233/DS-210053`). The article page records a Creative Commons Attribution
4.0 International license, so the converted Markdown and sidecars are
included for regression tests and documentation.

Included files:

- `soilandreyes2022_rocrate.md`
- `soilandreyes2022_rocrate.section_audit.json`
- `soilandreyes2022_rocrate.article.json`
- `paper_extraction.json`
- `paper_extraction.validation.json`
- `paper_extraction.quality.json`

The extraction records RO-Crate (Research Object Crate) as a lightweight
packaging approach for research artifacts, with emphasis on JSON-LD (JSON for
Linking Data) metadata, aggregation of files, and preservation-oriented
provenance.
