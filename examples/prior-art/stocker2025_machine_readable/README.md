# Machine-readable findings prior-art fixture

This fixture covers "Rethinking the production and publication of
machine-readable expressions of research findings"
(`10.1038/s41597-025-04905-0`). The article page records a Creative Commons
Attribution 4.0 International license, so the source PDF, converted Markdown,
and sidecars are included for regression tests and documentation.

Included files:

- `s41597-025-04905-0.pdf` (source PDF; checksum in `example_manifest.json`)
- `stocker2025_machine_readable.md`
- `stocker2025_machine_readable.section_audit.json`
- `stocker2025_machine_readable.article.json`
- `paper_extraction.json`
- `paper_extraction.validation.json`
- `paper_extraction.quality.json`

The extraction captures the manuscript's argument that scholarly findings
should be published in structured forms that stay linked to narrative
articles, provenance, and community review.
