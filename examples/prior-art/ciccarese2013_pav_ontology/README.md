# PAV prior-art fixture

This fixture covers "PAV ontology: provenance, authoring and versioning"
(`10.1186/2041-1480-4-37`). The article page records a Creative Commons
Attribution 2.0 Generic license, so the source PDF, converted Markdown, and
sidecars are included for regression tests and documentation.

Included files:

- `2041-1480-4-37.pdf` (source PDF; checksum in `example_manifest.json`)
- `ciccarese2013_pav_ontology.md`
- `ciccarese2013_pav_ontology.section_audit.json`
- `ciccarese2013_pav_ontology.article.json`
- `paper_extraction.json`
- `paper_extraction.validation.json`
- `paper_extraction.quality.json`

The extraction captures PAV (Provenance, Authoring and Versioning) as a
compact provenance vocabulary that complements the W3C provenance ontology
PROV-O by recording authorship, creation, derivation, and versioning for web
resources.
